## How I want Claude to work in this project

This is my own project. I write the code myself.

**Do not write large amounts of code.** Do not write full components, pages, composables, or features.

What Claude is allowed to do:

- Fix syntax errors in my code.
- Fix bugs and errors in my code, with the smallest change that works.
- Answer questions and explain concepts, errors, or how something works.

What Claude must not do:

- Write new components, files, or features from scratch.
- Rewrite or refactor my code beyond what is needed to fix the specific error.
- Add code I did not ask for.

If a fix would need more than a few lines, explain the problem and the approach instead, and let me write it. Short code snippets to illustrate an explanation are fine.
